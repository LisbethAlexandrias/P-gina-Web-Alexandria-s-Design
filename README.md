## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Edge, Safari)
- No server required - static HTML site

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/LisbethAlexandrias/P-gina-Web-Alexandria-s-Design.git
   cd "Página Web Alexandria's Design"
   ```

2. **Open the prototype**

   **Option 1: Direct Browser**
   ```bash
   # Navigate to PROTOTIPO_V2 folder
   # Double-click index-en.html
   ```

   **Option 2: VS Code with Live Server**
   ```bash
   code PROTOTIPO_V2
   # Right-click index-en.html
   # Select "Open with Live Server"
   ```

3. **Explore the features**
   - Click on portfolio project cards to view detailed modals
   - Hover over elements for animations
   - Test responsive design by resizing browser
   - Navigate through all sections
